## 机房位置先于配置：你的客户在哪，服务器就该在哪

外贸站的访客绝大多数在海外，机房离访客越近，首字节响应越快，这一点比 CPU 型号重要得多。

有第三方测评记录过一组对照：同一个外贸站先放在香港节点，国内打开飞快，但海外客户那边延迟 250ms 起步，Google PageSpeed 一直在 60 分上下；换到美国西海岸机房后，海外评分直接到 85。站点代码一行没改，改的只是物理距离。

选机房的规则很朴素：

- 客户集中在欧美：选美国机房，洛杉矶是外贸站最主流的落点。

- 两边都有：先保证主要成交市场，再考虑是否拆成两台机器。

## 线路是第二笔钱：为什么同一个机房能差出好几倍价格

机房只决定「大致距离」，线路决定「这条路上堵不堵」。国内访问海外服务器常走的三条优质线路是电信 CN2 GIA（AS4809）、联通 AS9929 精品网、移动 CMIN2（AS58807）。有社区测试对比称，普通 163 骨干线路在晚高峰丢包率可能超过 10%，而 CN2 GIA 基本能保持平稳。这类数据来自用户侧测试而非运营商公告，看趋势即可。

线路等级的差价是量级上的。以公开报价为例，同样 1GB 内存的入门档，某商家的香港 Premium 套餐约 $149.9/年，洛杉矶 Premium 套餐约 $36.9/年，差出约 4 倍。**多付的这笔钱买的不是配置，是延迟**：香港到大陆通常 10–30ms，洛杉矶要跨一个太平洋。

行业里常把产品线分成三档，这套分法各家叫法不同但逻辑通用：

| 档位 | 线路特征 | 适合谁 |
| --- | --- | --- |
| 顶级优化 | CN2 GIA + AS9929 + CMI 三网全优 | 国内外都要快，预算充足 |
| 折中优化 | CMIN2 或单一优质线路回程 | 预算有限，接受稍低一档 |
| 国际线路 | 无中国大陆特殊优化 | 客户全在海外，国内很少登后台 |

## 配置看内存和硬盘，不是核数

WordPress 加 WooCommerce 跑起来，真正的瓶颈是内存和磁盘 IO，CPU 核数基本不是瓶颈。一个正常优化的外贸站，日均一两千 PV，2GB 内存配双核就够。

- **刚起步、1–2 个产品页**：1GB / 1 核 / 20GB SSD
- **正常运营、有订单、日 PV 千级**：2GB / 2 核 / 40GB 左右，甜点档
- **多语言站、插件多、有会员系统**：4GB / 4 核 / 80GB
- **高流量、站群、多站点**：6GB 以上

**1GB 能不能跑 WordPress + WooCommerce？能，但很紧。** 内存要压在 600MB 以内，重型插件基本得禁掉，图片压缩和缓存必须做。预算允许就上 2GB，省下的调试时间比省下的那几十块钱值钱。多站承载的经验值是：4GB 稳跑 2–3 个轻量 WordPress，6GB 跑 3–5 个，8GB 跑 5 个以上。

拿到机器之后的上线流程，各家 VPS 大同小异：

1. **装系统**：建站选 Linux，Debian 12 或 Ubuntu 22.04 都行，三到五分钟
2. **装面板**：宝塔之类的图形面板，一行脚本装完，Nginx、PHP、MySQL 自动配好
3. **建站**：面板里一键部署 WordPress，绑域名，用 Let's Encrypt 配免费 SSL
4. **装主题和 WooCommerce**：选 Astra、Storefront 这类轻量主题，别用多功能大主题
5. **套 CDN**：Cloudflare 免费版，压延迟、挡爬虫
6. **跑分调优**：PageSpeed Insights 跑一遍，开缓存、压图片、延迟加载非首屏资源

Windows 只在必须跑 Windows 软件、远程桌面或 .NET 时才选，成本和资源占用都更高。熟练的话这条流程半天能走完，第一次做预留一个周末。最容易犯的错是上来就装一堆插件，外贸站最怕插件臃肿导致后台慢。
